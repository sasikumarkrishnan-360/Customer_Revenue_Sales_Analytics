# Customer Revenue & Sales Analytics

## Project Overview
This portfolio project analyses customer and sales transactions to understand revenue, cost, profit, customer value, product performance and sales trends.

## Business Objectives
* Identify high-revenue products and customers.
* Compare performance across cities and sales channels.
* Analyse monthly revenue trends.
* Calculate total revenue, total cost, total profit, profit margin and average order value.
* Present findings through an interactive Power BI dashboard.

## Tools Used
* PostgreSQL and SQL
* Python and Pandas
* Excel-compatible workbook
* Power BI and DAX
* Git and GitHub

## Project Workflow
1. Organise relational data and analyse it using PostgreSQL.
2. Clean, merge and explore datasets using Python and Pandas.
3. Calculate and validate metrics in the spreadsheet workbook.
4. Build an interactive Power BI dashboard.
5. Validate results and document business insights.

## Key Results
* **Total orders:** 30
* **Total revenue:** 17,190
* **Total cost:** 11,160
* **Total profit:** 6,030
* **Profit margin:** 35.08%
* **Average order value:** 573
